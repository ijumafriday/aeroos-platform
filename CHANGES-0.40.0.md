# AeroOS 0.40.0 — Operations Domain Completion

Operations now has a measured 84-capability software baseline covering provider governance and failover state, AIRAC/navigation-data lifecycle, EFB package release/distribution/acknowledgement/recall, DCS/load-control message acknowledgement, effective-dated airport/runway operational state, ACMI responsibility matrices, and electronic technical/journey-log continuity with offline revision controls.

Navigation remains compact: existing Operations Control, Dispatch, Crew, Rostering and Fatigue workspaces are unchanged, with one additional **Operations Data & Control** workspace containing contextual tabs for the new depth areas.

Master deficiency updates remain conservative. D024, D040, D044 and D059 move from MISSING to PARTIAL because software capability now exists; D014, D041, D042 and D043 remain PARTIAL with stronger implementation evidence. Production provider qualification, EFB/DCS integration acceptance, real AIRAC dataset qualification, cross-AOC ACMI acceptance and aircraft/offline tech-log trials remain outstanding external/runtime evidence.
