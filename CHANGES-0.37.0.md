# AeroOS 0.37.0 — Maintenance Domain Completion

This release completes the defined AeroOS Maintenance software scope while preserving the domain-first navigation model.

Highlights include first-class maintenance work orders; line-maintenance control; independent shift handover; governed station capability; workforce assignment/time booking; tool crib, reservation and calibration custody; base/heavy zone and access-panel control; task execution measurements, interruption/rework and independent inspection; engine/component shop induction through release with piece-part trace; outsourced work; material kitting; maintenance contracts/SLA and customer/TAT reporting; and cross-domain AOG recovery coordination.

The main navigation remains limited to Maintenance Control, Planning & Work Packages, and Task Cards & Certification. Detailed functions remain contextual to the Maintenance objects they control.

The master deficiency register remains evidence-based: affected Maintenance items move from MISSING to PARTIAL where appropriate because production-like execution/acceptance evidence is still required before they can be called globally COMPLETE.
